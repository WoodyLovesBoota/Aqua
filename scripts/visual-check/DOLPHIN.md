## 단계
1. 파이프라인: 파일 뼈대 + SDF v1, `dolphin` 스니펫, 스토어·스튜디오 분기, `pnpm bake:dolphin`, 첫 캡처 → D3
2. 실루엣: 4방향 시트 → 멜론·부리·등지느러미·flukes 비율 → D1
3. 플러시 다듬기: 두께·둥글기·smin, 3 LOD → D2
4. 재질: 배 경계 높이·눈줄 무늬, 팔레트 4색 → D4
5. 얼굴·부품 → D5
6. 유영 셰이더(상하 꼬리) → D6
7. 스튜디오 통합·매트릭스 → D7
8. 수조 DolphinSwimmer(점프 루틴·파문·회피·그림자) → D8
9. 성능 계측 → D9
10. 정리·문서·매트릭스 재촬영 → D10

## 단계별 기록
1. 체크리스트대로 한 번에 배선해 첫 베이크·캡처에서 형태가 맞았다.
4. 눈줄이 "안 보인다"고 4번 캡처를 반복 — 실제로는 있었다(픽셀 값). 중간에 `bellyMask = 1.0` TEST 로 스니펫 경로가 살아 있음을, playwright 응답 grep 으로 서빙 JS 가 최신임을 확인. 옅은 무늬는 눈으로 판정하지 말 것.
8. 점프가 안 터진 원인 3개를 순서대로 잡음: ① 열린 물 판정이 너무 엄격(여유 1.1) → 열린 지점을 골라 달려가도록, ② 지점 반경 1.6 < 회전 반경 2.2 라 영원히 맴돎 → 2.4, ③ 준비 중 장애물 회피를 껐더니 여울에 박혀 멈춤 → 회피 유지 + 8초 포기. 그리고 `resolveNoGo` 가 방갈로 뒤 벽 틈에서 벽 클램프와 번갈아 밀어 가두던 버그 → 활동 범위 밖으로 내보내는 변은 건너뜀. 검증은 `probe.mjs` + `?jump=` + `window.__aquaDebug`.
