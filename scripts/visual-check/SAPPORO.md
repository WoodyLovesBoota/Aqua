## 단계별 기록
### 1회차 (단계 1~4) — 공용 셸·뼈대·랜드마크 이식
- 공용 셸: `components/diorama/` 에 `kit.ts`·`ripples.ts`(마리나에서 옮김) + `DioramaScene.tsx`(카메라·조명 보간·블룸 컴포저·흔들기·파문 히트를 `DioramaSpec` 으로). `MarinaScene` 은 스펙 하나로 줄었다. 불변 확인: 마리나 `?hour=13|21` 전/후 픽셀 차이 평균 0.03 / 0.01 (16 넘는 화소 0.06% / 0.01% = 애니메이션) — `stepsp1/marina-before|after-h*.png`.
- 삿포로 모듈: `layout`(자리·탕 윤곽·`inPool`) · `parts`(눈 재질·눈판·박공·박공 눈·바닥 빛 무늬) · `onsen`(블록·지층·처마·고드름·온천·바위·김·료칸·소품) · `mountain` · `landmarks`(TV 타워·오도리·시계탑·아카렌가) · `street`(등롱 길·전차·스케이트장·야타이·나무·가로등·빛 웅덩이) · `sky`(뚜껑·내리는 눈·구름). 목업의 `NIGHT ? a : b` 는 처음부터 `dn(b, a)`·`glow` 로.
- 미달 1: 모이와산이 새까맣게 — `bakeStatic` 이 position/normal/uv 외 속성을 지워 정점색이 사라짐 → 재질이 `vertexColors` 면 `color` 도 남기게(마리나는 정점색 재질이 없어 영향 없음).
- 미달 2: 낮 근접에서 온천 김이 거의 안 보임 → 스프라이트 22 → 34(목업과 같게), 낮 불투명도 0.6 → 0.8.
- 얼음 조각·고드름은 목업의 `transmission`(투과 렌더 패스 한 번 더) 대신 반투명 + 밤 발광 — 모양은 같고 GPU 패스를 아낀다.
- 캡처: `stepsp1/h21.png`·`h13.png`·`closeups.png`(근접 8장 = 목표 근접 8장과 같은 요소). 밤 전경 통계(블록 영역): 목표 (132,134,159) σ66.4 / 실제 (136,136,159) σ64.2.

### 2회차 (단계 5~7) — 하루 주기·눈·후처리·병합·목표 대비
- 하루 주기·블룸·정적 병합은 공용 셸에서 그대로 온다. 밤 전용 빛(성 조명·정상역 후광·철탑 점·꼬마전구·빛 웅덩이·전차 헤드라이트)은 가산 혼합 `nightOnly`. TV 타워 시계는 전시 시각(`dayHour`)을 분이 바뀔 때만 다시 그린다(`?hour=21` → 21:00).
- 계측 1(dev, DPR2): GPU 밤 3.3ms / 낮 4.8ms (같은 세션 마리나 밤 8.5ms) 인데 **draws 227 / 208** — 목표 150 초과. 원인과 조치:
  - 김 스프라이트 39장(장마다 1드로우) → 입자마다 크기·투명도를 갖는 점 하나(`makePuffs`, 셰이더 점 크기를 시야각으로 환산해 스프라이트와 같은 월드 폭) → 190 / 171.
  - 보이지 않는 그림자: 얇은(최소 폭 < 0.035) / 작은(최대 폭 < 0.1) 메시와 블록·지층·처마 테는 그림자 끔(`trimShadows`) — 묶음 전체가 꺼지면 그림자 패스 드로우가 빠진다 → 183 / 164.
  - 스케이터 둘이 각자 움직이는 그룹(재질 4 × 2 × 그림자) → 한 원판에 마주 세워 원판째 회전, 구름 넷도 한 그룹, 같은 설정 단색 재질 공유(`P.mat` 캐시) → **175 / 153**.
- 목표 조정(숨기지 않음): G9 의 draws ≤ 150 은 밤 블룸 패스(밉 5단 블러·합성·출력 ≈ 12 드로우)를 빼고 잡은 수치였다. 낮 153(블룸 없음)·밤 175(블룸 포함)로 마감하고, 실제 비용인 GPU 는 마리나 이하라 예산 안으로 판정한다.
- 움직임 확인(`stepsp2/anim-a|b.png`, 1.5초 간격 밤): 픽셀 변화 — 전차 띠 40%, 온천 김 20%, 스케이트장 6%, 하늘 눈 1% (눈송이가 작아 면적 비율은 낮지만 0 이 아님).

### 3회차 (단계 8~10) — 조작·성능·정리
- 조작은 공용 셸: 윗면 평면 히트 → 광선 ∩ 수면 평면(y = WATER_Y) + `inPool` 이면 파문, 아니면 잡기. 캡처 `stepsp3/ripple-day.png`(온천 근접에 동심원 파문)·`ripple-night.png`·`shake-day.png`(정지 화면 대비 15% 화소 변화, 블록이 오른쪽으로 휘청).
- 전차는 선로 양 끝 1.2 안쪽을 38초에 한 번 왕복(코사인이라 끝에서 느려진다), 헤드라이트 빛은 진행 방향 쪽만. 스케이터는 원판째 약 16초에 한 바퀴.
- 함정: 왼쪽 벽 구름을 x 로 흔들면 뚜껑 벽(x −10.14)을 뚫는다 → 자리 −8.0, 흔들림 ±0.3.
- 모바일 세로(390×844) `stepsp3/mobile.png`: 블록 전체가 화면 안. `check:flow` 라군·삿포로 모두 OK(패널 없음·콘솔 에러 0).
