## 단계별 기록
### 1회차 (단계 1~4) — 뼈대·형태·재질·디테일 이식
- 목업(`target-mockup.html`)을 랜드마크별 모듈(`src/components/marina/*.ts`)로 옮김. 재질은 처음부터 낮/밤 한 쌍(`Kit.std({ color: dn(day, night), glow })`) — 목업의 `NIGHT ? a : b` 를 그대로 옮기면 하루 주기 때 다시 지어야 해서.
- 캡처 `stepmb1/h19.7.png`·`h13.2.png`: 배치·형태·하루 주기 모두 목표와 같은 구도. 미달 2: ① 아트사이언스가 목표보다 1.45배 큼 — 목업 1판의 배율이 layout 에 딸려 옴 → 1 로. ② `PCFSoftShadowMap has been removed` 경고(three r186) → `PCFShadowMap`.
- 함정: 새 라우트를 dev 서버가 뜬 뒤에 만들고 ClientOnly 에 export 를 덧붙이면 turbopack 이 `MarinaClient` 를 undefined 로 들고 있음(500) → 서버 재시작으로 해결. Next 16.4 dev 는 첫 실행이 업그레이드 안내로 멈추고 5분 안에 같은 명령을 다시 실행하면 계속 뜬다.
- 계측(dev, DPR2, 1440×900): marina 60fps · **draws 5229** · tris 1.09M · GPU 중앙값 16.6ms / 라군 draws 107 · GPU 4.55ms → G9 ✗. 2회차에서 정적 메시 재질별 병합.

### 2회차 (단계 5~7) — 하루 주기·후처리·병합·목표 대비 수정
- 하루 주기는 1회차부터 재질 보간으로 들어가 있었음(`nightOf(hour)`: 17:30~20:00 저녁, 5:00~7:30 새벽). 조명·하늘 두 장 교차·별/달/구름·블룸 세기를 같은 k 로.
- 병합: `bakeStatic(block)` 이 정적 메시를 재질·그림자 설정별로 합침(돌아가는 플라이어 바퀴는 따로 병합, 물방울·파문·구름·수면은 `keepDynamic`). draws 5229 → 535. 함정: 바퀴 그룹 자체가 dynamic 이라 `bakeStatic(wheel)` 이 루트에서 바로 return → 루트는 예외로. 캡슐을 바퀴와 같이 병합하려고 역회전 제거(캡슐 축이 바퀴 축과 나란해 돌아도 모양이 같다).
- GPU 가 그대로(17ms)라 A/B(`?ao=0|1`·`?bloom=0`·`?shadow=0`): 전체 해상도 GTAO 와 블룸이 각각 수 ms. → AO 기본 끔(`?ao=1` 로만, 밤 화면 통계 차이 없음: 평균 131.8 vs 131.5), 블룸 1/4 해상도, 그림자 2048, **낮(k=0)엔 컴포저를 건너뛰고 바로 그림**(MSAA 도 산다). draws 312(밤)/287(낮).
- GPU(dev, DPR2, 같은 세션, 측정마다 크게 출렁임): 낮 5.2~6.7ms · 밤 7.1~12.2ms · 라군 4.55~5.14ms. 낮은 예산(1.5배) 안, 밤은 경계~초과 → 3회차에서 삼각형 감축.
- 목표 대비(`stepmb2/cmp-night.png`·`cmp-day.png`·`closeups.png`): 근접 6장은 목표와 사실상 같음. 미달 2: ① 낮 배경이 크림색 — 바로 그리는 경로에선 배경이 톤매핑되지 않음 → 경로마다 배경색(`PAPER_POST` / `PAPER_DIRECT`), 수정 뒤 픽셀 (235,231,224) = 라군 종이색. ② 밤 후광이 약함 → 1/4 해상도 보정으로 세기 0.72·반경 0.32(0.85 는 하늘에 안개가 깔림). 완전한 밤(`?hour=21`) 통계: 목표 평균 RGB (127,119,150)·σ 56.1 / 실제 (131,123,152)·σ 55.0.

### 3회차 (단계 8~10) — 조작·성능·정리
- 조작: `ripples.ts` — 수면 재질 onBeforeCompile 에 파문 8개(법선 흔들기 + 마루 빛, 변위 없음). 포인터는 보이지 않는 윗면 평면 + 옆면 상자만 레이캐스트하고, 만 판정은 광선 ∩ 수면 평면(y = WATER_Y) + `inBay`. 땅·지층을 잡으면 라군과 같은 푸딩 전단 스프링(블록이 높아 상한 0.12, 1.8Hz ζ0.09). 캡처 `stepmb3/interact.png`(동심원) · `shake-sheet.png`(낮/밤 휘청). `?debug` 면 `__aquaDebug.marina` 에 상태.
- 함정: 흔들기 캡처가 정지 화면과 같아 히트 상자를 의심했으나, 실은 테스트 좌표 (1000,800) 이 블록 밖 종이였음 — 픽셀을 찍어 지층 자리 (900,820) 를 찾고 해결. 히트 상자는 아래 지층 띠·둥근 모서리까지(높이 +0.55, 폭 +0.3)로 넓혀 둠.
- 성능: 분할 축소(레인트리 구 9×6, 둑·난간·LED 관 400→240, 연꽃 12×30, 뚜껑 모서리 5) → tris 646k → 559k.
