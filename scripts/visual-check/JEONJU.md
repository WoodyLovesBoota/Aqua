## 단계별 기록
### 1회차 (단계 1~4) — 라우트·블록·부품·랜드마크·마을
- 삿포로에서 만든 범용 소도구(`place`·`makePuffs`·`trimShadows`)를 `components/diorama/fx.ts` 로 올림(삿포로 `parts` 는 다시 내보내기만). 전주는 `layout`·`parts`(재질 + 기와지붕·한옥·청사초롱·나무·장독대·돌담) · `ground`(블록·전주천·유등) · `landmarks`(남천교·한벽당·오목대/자만·풍남문·전동성당·경기전) · `town`(길·한옥 2·남부시장·야시장·극장·합죽선·나무·초롱·빛 웅덩이) · `sky` · `JeonjuScene`(스펙).
- 목업에서 미리 잡은 함정을 처음부터 반영: 기와 곡면 `pow(t, 1.45)` 에 음수 t(−1e-16)가 들어가면 NaN → t 를 [0,1] 로 고정. 높이 0 원기둥은 법선이 NaN 이 되어 밤 블룸이 화면을 덮는다(목업에서 실제로 발생) → 높이 0 부품 없음. 내림마루는 직선이면 오목한 지붕 위로 뜨므로 곡면을 따라 관으로.
- 병합이 재질 배열 메시를 건너뛰므로(시장 셔터·극장 간판) 면마다 별도 평면으로.
- 유등은 밤 전용 인스턴스 메시 둘(등·물빛)로 물길을 따라 흐름 — 움직이는 9개가 2 드로우.
- 캡처 `stepjj1/h21.png`·`h13.png`·`closeups.png`: 근접 8장 목표와 같은 요소. 통계(블록 영역) 밤 목표 (121,115,136) σ74.3 / 실제 (124,117,136) σ73.6, 낮 목표 (202,196,185) σ41.6 / 실제 (200,194,181) σ45.2. 미달 없음.

### 2회차 (단계 5~7) — 하루 주기·움직임·병합·드로우 감축
- 하루 주기·블룸·병합은 공용 셸. 밤 전용: 보름달·달무리·별·유등·빛 웅덩이·성당/풍남문/한벽당 후광·꼬마전구 줄. 은행잎은 낮/밤 색만 바뀐다.
- 계측 1(dev, DPR2): draws **212(밤)/187(낮)** — 목표 200 초과. 원인: 색·그림만 다른 작은 부품이 재질을 하나씩 가짐(벽화 6·차양 5·먹거리 6·벽화집 지붕 6·한복 6·포스터 3). 조치: 벽화·차양은 아틀라스 텍스처 한 장 + 부품마다 uv 칸(`atlasUV`), 나머지는 정점색 재질 하나(`tint` + `P.VC`/`P.VC_GLOW`, `bakeStatic` 이 정점색 재질의 color 속성을 남긴다 — 삿포로 때 고친 것) → **160 / 135**. 캡처 `stepjj2/atlas-check.png` 로 칸이 맞게 붙은 것 확인.
- 움직임(`stepjj2/anim-a|b`, 1.5초 간격): 전주천 유등 1.85% 화소 변화. 미달: 야시장 김이 차양 밑이라 안 보임 → 차양 앞·위로 옮기고 진하게. 흰 김이 흰 줄무늬·밝은 흙 위라 여전히 옅다(목표 그림도 거의 안 보임) — 은은한 효과로 둔다. 은행잎 160 → 240 · 크기 0.07 → 0.095.

### 3회차 (단계 8~10) — 조작·성능·정리
- 조작은 공용 셸(`inStream` 판정). 첫 파문 캡처가 차이 0.09% 였던 건 클릭 좌표가 청연루 지붕 위였기 때문(히트 평면은 지붕에 가리지 않지만 광선 ∩ 수면이 물길 밖) → 상류 열린 물(640,240) 에서 파문 링 확인(그 영역 3.5% 변화) `stepjj3/ripple-crop.png`. 흔들기 `shake-day.png` 17.9%.
