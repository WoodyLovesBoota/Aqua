## 단계
1. 파이프라인: 파일 뼈대(Sdf·Manifest·Turtle·Parts·Swimmer 자리), PlushMaterial `turtle` 스니펫, 스토어·스튜디오 분기, `pnpm bake:turtle`, 첫 캡처 → T3
2. 실루엣: 4방향 시트 → 등딱지 비율·지느러미 각도·머리 → T1
3. 플러시 다듬기: 돔/배딱지 두께·테두리·smin, 3 LOD → T2
4. 재질: 갑판 무늬·배 마스크, 팔레트 4색 top 뷰 → T4
5. 얼굴·부품 → T5
6. 유영 셰이더 → T6
7. 스튜디오 통합·매트릭스 → T7
8. 수조 TurtleSwimmer(숨쉬기 루틴·회피·그림자) → T8
9. 성능 계측 → T9
10. 정리·문서·매트릭스 재촬영 → T10

## 단계별 기록
1. 뼈대를 만타 파일에서 sed 로 복제. **몸이 안 그려지고 부품만 보임** → 갑판 무늬 스니펫의 `float col` 이 프래그먼트의 `vec3 col` 과 이름 충돌(셰이더 컴파일 실패). 종별 스니펫 변수는 접두사를 붙인다.
2. **지느러미가 통째로 없음**(bbox z ±0.97): 지느러미 판을 눕히는 x축 회전 부호가 반대라 등딱지 속으로. 이후 좌우 오일러를 각각 적어 비대칭(−1.35/+1.70)이 났다 → 오른쪽만 정의하고 |z| 로 평가해 정확한 거울상.
3. 축소 시트에서 앞지느러미가 "앞으로 쓸렸다"고 오판 → 원본 확대로 뒤로 쓸린 것 확인. 판단은 원본 해상도로.
4. 격자 무늬 1차는 반 칸 어긋난 사각 격자라 십자/격자처럼 보임 → 육각 타일 거리식(두 격자 중 가까운 중심, hex 거리). 무늬가 지느러미까지 번져 |z| < 0.9 제한.
8. 1차: 거북이 섬 왼쪽 물가로, 상어가 만타 옆에 반복 → `shallow()` 로 얕은 바닥 전진 금지, 상어 분리·목표 회피 추가, 만타 섬 여유 1.0(수심 때문에 화면에서 섬과 겹쳐 보임).
9. 캡처 프로세스 멈춤 재발 → `shot.mjs` 가 브라우저 종료 5초 뒤 강제 종료하도록 수정.
