# 이상향 (사용자 정의)
"인형 같은 상어를 완벽하게 커스터마이징 → 아름다운 바다 같은 큐브 수조에 풀어넣기. 렉 없이. 빗질 등 잡기능 없이."

## 체크리스트 (각 단계마다 비교)
A. 인형 형태   : 매끈하고 통통한 플러시 인형 실루엣, 솔기/눈/입이 또렷. 삐죽한 노이즈 없음.
B. 커스터마이징: 색/눈/입/머리/목/얼굴/솜/꼬리 모든 옵션이 정확히 렌더, 수조로 그대로 이어짐.
C. 렉 없음     : 로딩 long task < 100ms, 프레임당 tris < 500k, draw < 40, 60fps, worst frame < 20ms.
D. 수조        : 큐브형 물, 바다 같은 색/빛(커스틱·그라데이션), 상어가 안에서 선명하게 보임.
E. 코드        : tsc/lint 0 에러, 죽은 코드(빗질/쓰다듬기/도구) 없음, 콘솔 에러 0.

## 단계 계획
1 지오메트리 베이크(정적 자산) → 메인스레드 블로킹 제거
2 퍼 셸 28겹 → 단일 패스 플러시 머티리얼
3 빗질/쓰다듬기/도구/잡동작 삭제, UI 정리
4 인형 형태·얼굴 다듬기
5 커스터마이징 매트릭스 캡처 검증
6 수조 속 상어 가시성·물 재질
7 수조 미관(빛·커스틱·배경)
8 유영 모션 자연스러움
9 코드 완성도(lint/tsc/README/죽은 코드)
10 최종 종합 비교
