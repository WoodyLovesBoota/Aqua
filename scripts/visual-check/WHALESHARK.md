## 단계
1. 파이프라인: 파일 뼈대 + SDF v1, `whaleshark` 스니펫, 스토어·스튜디오 분기, `pnpm bake:whaleshark`, 첫 캡처 → W3
2. 실루엣: 4방향 시트 → 머리 폭·입·능선·지느러미 비율 → W1
3. 플러시 다듬기: 두께·능선 둔덕·smin, 3 LOD → W2
4. 재질: 별무늬+격자, 배 마스크, 팔레트 4색 → W4
5. 얼굴·부품 → W5
6. 유영 셰이더 → W6
7. 스튜디오 통합·매트릭스 → W7
8. 수조 WhaleSharkSwimmer(여과 섭식 루틴·회피·그림자) → W8
9. 성능 계측 → W9
10. 정리·문서·매트릭스 재촬영 → W10

## 단계별 기록
1. 체크리스트대로 한 번에 배선 → 첫 베이크·캡처에서 형태·무늬·얼굴이 거의 통과. 이전 두 루프의 함정(스니펫 변수 접두사 `w*`, 오른쪽 지느러미만 정의 + |z|)을 처음부터 피했다.
2. 능선 3줄이 별무늬에 묻혀 안 보임 → 반지름 0.07→0.1, smin 0.12→0.1. 그래도 옅다(플러시 둔덕으로 인정).
7. 종이 5개가 되자 분할 버튼이 패널 폭(232px)을 넘쳐 "Whale" 이 잘림 → `.segmented` 를 flex-wrap + 1px 틈 배경선으로 바꿔 2줄.
9. tris 351.8k 로 예산 350k 초과 → 목표를 낮추지 않고 고래상어 스티치 캡슐(입 15·아가미 10)의 분할을 4·8 → 2·6 으로 줄여 347.6k.
