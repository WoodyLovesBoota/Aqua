## 단계
1. 뼈대: `Reef.tsx`(Builder 패턴, 정점 색 1 재질 → 1 드로우) + 군락 3곳 좌표(바닥 깊이 표로 고름) + 자리표시 덩어리 → 전체 캡처 → G1
2. 산호 형태 A: 가지(재귀 분기 튜브) · 덩어리/뇌(지터 구) · 손가락(캡슐 묶음) → 확대 시트 → G2 일부
3. 산호 형태 B: 테이블(기둥 + 울퉁 원판) · 부채(캔버스 알파 격자 평면) · 말미잘(돔 + 촉수) → 확대 시트 → G2
4. 색·재질: 군락별 팔레트(sRGB→선형), 깊이 색조 확인, 모래·수초와 픽셀 차 → G3
5. 열대어 메시(몸+지느러미 1 지오메트리, 인스턴스 1 드로우) + 무늬 셰이더 4종 + 구슬 눈, 정지 배치 → 확대 시트 → G4 G5
6. 열대어 움직임: 군락 반경 배회 + 꼬리 파동(정점 셰이더, 인스턴스 위상) + 분리 + 숨기 → 프레임 diff·probe → G6
7. 산호 움직임: 말미잘 촉수·부채 정점 흔들림(정점 색 가중) → 프레임 diff → G7
8. 통합: 소크 60s · flow 데스크톱/모바일 · 모바일 캡처 → G8
9. 성능 계측(기준선과 같은 조건) · 조정 → G9
10. 정리: README · 결과표 · 메모리 · 스튜디오 diff · 해시 확인 → G10

## 단계별 기록
1. 뼈대(`stepc1`): `Reef.tsx` 빌더(정점 색 1 재질). 첫 캡처는 WebGL 실패 화면 — Icosahedron(Polyhedron) 은 인덱스가 없고 Cylinder·Capsule 은 있어 `mergeGeometries` 가 null 을 돌려줬다 → `add()` 에서 전부 `toNonIndexed()`. 자리는 맞았지만 조각이 드문드문 작아 '조약돌' 로 읽힘.
2. 형태 A(`stepc2`): 해바라기 나선(황금각) 배치로 조각끼리 닿는 둔덕 + 잔돌 8. 가지 산호는 trunk 0.3h 로는 분홍 점 → 0.42h·자식 0.78 배. 뇌 산호는 크림색이 물 색조에 눌려 회색 돌 → 따뜻한 노랑(#f7c46a) + 고랑 0.55. 팔레트 전체를 한 단계 진하게(물속은 색유리 곱이라 채도가 깎인다).
3. 형태 B(`stepc3`): 테이블(기둥 + 지터 원판 + 혹 16)·말미잘(돔 + 촉수 46)·부채(알파 격자 평면). 부채는 세 번 고쳤다 — ① 선 1~7px 는 점으로 사라짐 → 3~12px ② 세로 평면이 위 조명을 못 받아 검붉음 → 법선을 (0, .9, .44) 로 세우고 DoubleSide 대신 앞·뒤 두 장(FrontSide; DoubleSide 는 뒷면 법선을 뒤집어 아래를 본다) ③ 그래도 어두움 → **투명 캔버스 map 의 알파 번짐**(투명 픽셀 RGB 가 검정이라 밉맵에서 선이 검게 섞인다) → 검정 배경 흰 선을 `alphaMap` 으로만.
4. 색(`stepc4`): 조명 없는 재질로 비교해 조명 문제가 아님을 확인. 붉은 계열은 물속에서 자주색으로 가라앉으므로 가지 끝·말미잘 촉수는 연분홍(blush)·부채는 라벤더/블러시/피치 같은 밝은 톤으로. 호(arc)는 가지 범위(±50°) 안으로 — 밖으로 나가면 레이더처럼 보였다.
5. 열대어(`stepc5`): 몸(구 → 머리 둥글고 꼬리 가늘게) + 꼬리(V) + 등·배 지느러미를 한 지오메트리로, 인스턴스 1 드로우. 무늬는 로컬 xy 로 프래그먼트에서(띠·타원 팔레트·줄무늬·눈점), 구슬 눈은 양 옆 (0.32, 0.06). `?focus=<군락>` 근접 뷰를 추가해 판정. 블루탱 검정 팔레트는 사각 → 타원 − 타원. **돌고래·상어가 섬 앞 군락을 뚫고 지나감** → 산호 군락을 `NO_GO.reefs` 원으로 등록(`blocked`/`pushAway`/`resolveNoGo`). 그러자 navsim 에서 고래상어가 리조트 띠·산호 원(+margin 1.2)·벽 사이 주머니에 갇힘 → 산호 원은 clearance < 1 인 종(상어·거북·돌고래)만 보고 margin 은 0.6 으로 깎음(고래상어·만타는 얕은 바닥 판정으로 어차피 모래톱에 못 온다). 모래톱 군락은 (4,3.5)→(3.4,3.8) r 1.15 로 벽에서 떼어 띠가 안 생기게.
6. 움직임(`stepc6`): `fishsoak.mjs` 30s — 10마리 모두 r/R ≤ 1.05, 30초 이동 7.8~12.8, 속도 0.13~1.30(질주·도망 포함), 문제 0. 도망 샘플이 58/300(19%) 로 과민 → 감지 거리 1.5→1.15, 수직 1.3→1.0. probe(`flee.png`): 거북 접근 시 물고기들이 산호 사이로 내려감.
7. 흔들림(`stepc7`): `onBeforeCompile` 로 `aSway` 정점 속성(촉수 끝·부채 위) 만큼 사인 흔들림. 0.6초 차 두 프레임 diff: 말미잘 박스 8473px 변화, 정적 덩어리 박스 0px.
8. 통합(`stepc8`): 소크 60s problems 0 · fps 61(5종 범위 정상), 모바일 390×844 캡처에서 세 군락이 보임. flow 는 아래 결과표.
9. 성능(`stepc9`→`stepc9b`): 1차 tris +96k. 가지 마디 구슬(46개 × 48 tris × 9그루)이 가장 큰 낭비 → 끝 구슬(5×4)만 남기고 자식 밑반지름을 부모 윗반지름(0.8r)에 맞춰 이음새를 감춤. 잔돌 Icosahedron detail 2→1, 손가락 캡슐 (3,7)→(2,6), 촉수 46→36·(2,5)→(1,5), 물고기 구 20×14→16×11. 2차 +54k. GPU 는 변화 없음(2.27→2.24).
10. 정리: `?focus=<군락>` 근접 카메라·`fishsoak.mjs`·`zoom.py` 는 점검용으로 남김. flow 실패는 스튜디오 h1 제거(다른 세션) — 스튜디오 쪽 세션이 flow.mjs 의 h1 기대를 같이 고쳐야 한다.
