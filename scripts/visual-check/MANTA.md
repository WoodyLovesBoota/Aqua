## 단계 (각 단계: 구현 → 캡처 → 목표와 비교 → 미달이면 같은 단계 안에서 수정)
1. 파이프라인 일반화: 베이크 스크립트를 생물별로, 로더 공용화, 만타 SDF v0(몸통+날개) 베이크·첫 캡처 → M3
2. 실루엣: 날개 평면형·머리지느러미·꼬리·등지느러미, top/side/front 캡처로 비율 확인 → M1
3. 플러시 다듬기: 단면 렌즈형, 둥글기, 노이즈·구멍, LOD 3개 비교 → M2
4. 재질: 만타용 배 마스크·솔기, 팔레트 → M4
5. 얼굴·부품 → M5
6. 유영 셰이더 → M6
7. 스튜디오 통합(종 선택·스토어·제목·매트릭스) → M7
8. 수조 통합(AI·그림자·회피) → M8
9. 성능 계측·조정 → M9
10. 정리·문서 → M10

## 단계별 기록
1. 파이프라인: `sharkFormat`→`creatureFormat`, `sharkMesh`→`creatureMesh` 래퍼, `PlushMaterial` 이동 + 종별 `SWIM`/`BELLY` 스니펫. Node 가 `@/` 를 못 풀어 `--import ./scripts/ts-alias.mjs` 훅 추가.
2. 실루엣: 첫 캡처는 몸이 납작·머리지느러미 막대·등지느러미 뾰족. 앞전 쓸림, 지느러미 y×1.9 납작 노, 등지느러미 축소. `?view=` 포즈 추가(top/below 가 뒤집혀 있어 교정, front/back 도).
3. 플러시: 몸통 ry 0.5, 날개 뿌리 0.34, smin 0.45 로 몸↔날개 능선 제거. `?still=1` 없이는 고정 포즈에서도 날갯짓이 돌아 lo LOD 날개가 휜 것처럼 보였다 → 정지 옵션.
4. 재질: 처음 어깨 무늬를 띠로 넣어 줄무늬처럼 보임 → 사선 안쪽을 채우는 패치로. 머리지느러미까지 밝아져 x ≤ 1.0 제한.
5. 얼굴: 입 커브(x 1.5, z ±0.3)가 머리지느러미에 투영됨 → 지느러미 간격 0.5, 입 x 1.3 z ±0.2. 볼터치는 배에서 보여 뺨 옆으로.
6. 유영: 프레임 4장이 같아 보여 픽셀 diff 로 확인(차이 있음) → 진폭 0.5→0.62.
7. 스튜디오: `Segmented` 컴포넌트, 종별 COPY 표, 만타 배율 0.62→0.7. matrix.mjs 가 state 전체(config/manta/species)를 주입하도록.
8. 수조: `lagoonNav.ts` 로 수조 상수·blocked/randomTarget/pushAway/그림자 텍스처 추출. 1차: 만타가 얕은 물가로 떠올라 섬 금지 구역·보도 아래 진입, 상어 옆에 자주 붙음 → 되밀기 안전망·전방 2점 탐지·clearance 0.9·상어 3.5 밖 목표·밀어냄 2.2/×4.
9. 성능: 부품 2그룹(gloss/matte)→1그룹으로 draws 65→63. 캡처 스크립트가 가끔 브라우저 종료에서 멈춰 `wait` 가 안 끝남 → 해당 PID 만 kill.
10. 상어 재베이크(스냅 2회로 해시 변경, 정점·삼각형 수 동일) 뒤 매트릭스로 동일 확인, README·문서.
