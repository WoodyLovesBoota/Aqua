# 해상 비행기(수상기) 10단계 — 결과 정의 (2026-10-11)

기준선(before): `/sea` 라군 하늘엔 해·달·별·구름뿐, 날아다니는 것은 없다. 계측 기준은 이 루프 시작 직전 같은 기기에서 다시 잰 `stepp0`(M4 Pro · 1440×900 · DPR 2, 개발 서버).
요청: "`aquamodel.mov` 를 참고해 해상 비행기 하나를 만들어 착륙 → 이륙 → 한 바퀴 돌기를 반복."
참고 영상 분석(`aquamodel.mov` 4.8초, 1042×584): 흰 동체 + 청록 포인트(기수 카울·날개 끝·수직 꼬리·플로트)의 작은 **고익 단발 수상기**(플로트 2개, 지지대). 화면 밖 오른쪽에서 낮게 들어와 블록 **앞바다**(오른쪽 앞)에 착수해 왼쪽으로 활주하며 항적을 남기고, 그대로 이륙해 블록 왼쪽 벽을 넘어 상공으로 올라간 뒤 블록 바깥을 크게 선회해 돌아온다. 비행기는 토이 비율(방갈로 1.5채 정도 날개폭).
품질 기준 캡처: `.visual-check/stepn15/h12.png`(한낮 전체) — 리조트 소품(보트·방갈로)의 디오라마 톤에 맞춘다.

## 설계 결정 (기본값 — 묻지 않고 정함)
- 모델 = 프로시저럴 지오메트리 정점 색 **1 메시 1 드로우**(보트와 같은 `MeshStandardMaterial vertexColors`). 프로펠러는 같은 지오메트리의 `aPart=1` 정점을 정점 셰이더에서 허브 축으로 돌린다(별도 드로우 없음). 야간 항법등(좌 빨강·우 초록·꼬리 흰색)은 `aPart` 2/3/4 로 `ENV.uLamp` 에 따라 발광.
- 크기: 길이 ≈ 1.15 · 날개폭 ≈ 1.5 · 플로트 길이 ≈ 0.9 (보트 1.0 · 방갈로 0.45 와 같은 토이 비율).
- 경로 = **닫힌 CatmullRom 스플라인 한 바퀴**(결정적, 매끈함 보장): 오른쪽 바깥 상공 → 강하 → 앞바다 활주로(`z ≈ 2.0 · x +5.5 → −4`, 섬·산호·방갈로 금지 구역 밖) 착수 → 활주 → 이륙 → 왼쪽 벽 넘어 상승 → 블록 뒤를 돌아 → 오른쪽에서 다시 진입. 구간별 속도(비행 3.0 · 착수 1.6 · 활주 0.9 · 이륙 1.6). 한 바퀴 ≈ 35~40초. 돔(젤리 뚜껑)은 통과한다 — 영상처럼 블록 바깥을 돈다.
- 물 위에선 블록 흔들림(전단·바닥 변위)을 따라가고(고도 0→1 에서 블렌드), 공중에선 따라가지 않는다. 착수 순간 물보라(`splash`) + 활주 중 플로트 자리에 0.2초마다 작은 파임(항적).
- 자세: 진행 접선 → yaw/pitch, 요 각속도 → 뱅킹(최대 0.55rad), 착수 직전 플레어(기수 들기), 이륙 회전.
- 그림자: 블롭 1장 — 블록 발자국 안이면 수면 위, 밖이면 종이 바닥 위. 고도가 높을수록 크고 옅게, 빛 반대쪽(Shadows 의 OFF_X/OFF_Z)으로 밀린다.
- 점검용: `?plane=off`(끄기, A/B) · `?plane=park`(활주로에 정지) · `?plane=<초>`(경로 시작 위상) · `?focus=plane`(근접 뷰, `&view=top|side|front|q`) · `window.__aquaDebug.plane`(`&debug`).

## 단계별 기록
1. 뼈대(`stepp1`): `Seaplane.tsx`(상태·블록 따라가기·항적) + `seaplanePath.ts`(닫힌 CatmullRom + 조종점별 속도·피치 보정, 호 길이 보간) + `seaplaneModel.ts`(정점 색 1 메시, aPart 프로펠러/항법등). 첫 경로는 블록 뒤 고도 6·z −12 로 잡았더니 **화면 위로 벗어났다**(디오라마 카메라는 블록 뒤쪽이 프레임 꼭대기). 카메라 투영 스크립트(SeaScene 의 CAM 식 그대로)로 조종점을 NDC 로 찍어 |x| < 0.92, y < 0.9 안으로 다시 잡았다 — 뒤쪽은 z ≈ −8.8 · 고도 3.5(돔 높이 4 보다 낮지만 발자국 밖이라 돔 뒤 벽 너머로 보인다).
2. 실루엣(`stepp2/sheet.png`): 동체 회전체(LatheGeometry — y 축 회전체라 (r, x) 로 넣고 z −90°) + 고익 상자 + 청록 날개 끝 + 꼬리(Extrude 사다리꼴 + 수평 안정판) + 플로트 캡슐 2 + 지지대(두 점 잇는 상자) + 카울·스피너·프로펠러. 근접 뷰 거리 3.4 는 날개가 잘려 4.4 로.
3. 재질(`stepp3`): 창을 튀어나온 상자로 두니 동체 밖으로 삐죽했다 → 정점 색 삼각형 다수결로 칠해 봤더니 톱니 경계 → **동체보다 0.005 큰 부분 회전체 띠(phiStart/phiLength)** 로 바꿔 또렷한 창. **함정**: Lathe 점을 x 감소 순서로 넣으면 면이 안쪽을 봐 창 띠가 동체 속에 숨고 동체 음영도 납작해진다 — 점은 lathe-y 증가 순서로.
4. 디테일(`stepp4/sheet.png`): 프로펠러는 같은 지오메트리의 aPart=1 정점을 정점 셰이더에서 허브 x 축으로 회전(0.3초 차 두 캡처 diff: 프로펠러 영역 4.7% vs 날개 0.1%). 항법등은 `ENV.uLamp` × 2.2 발광(4.0 은 흰색으로 포화) — 밤 캡처에서 좌 빨강·우 초록·꼬리 흰색, 낮엔 어두운 구슬.
5. 경로(`stepp5/sheet.png`, `check:plane`, `planesoak.mjs`): 첫 경로의 오른쪽 진입이 V 자 꺾임(요 각속도 10 rad/s) → 오른쪽 바깥 사분원(중심 11,−1.1 · r 3.5)으로 활주로 연장선에 정렬, 왼쪽 선회도 넓혀 최대 1.58 rad/s. 활주로 z 는 2.0 → 1.85(정적 보트 3.9,2.9 와 날개 끝 간격). 스플라인이 활주 구간에서 −0.034 처져 물 아래로 → y<0 이면 0 으로 클램프(접선 y 도 0). 소크 70s: taxi>takeoff>climb>loop>approach 반복, 한 바퀴 30.6초, 물 위 금지 구역 0건, 야자수·방갈로 간섭 0건. **함정**(재발): probe.mjs 는 `&debug` 없이는 `__aquaDebug` 가 없다 — 5개 캡처를 통째로 날렸다.
6. 수면(`stepp6`): 착수 순간 `splash` 0.9 → simdebug 편차 평균 0.76(최대 143/최소 119). 활주 항적은 플로트 뒤 0.2초마다 반지름 0.32·−0.09×속도(0.05 는 앞에서 안 보여 올림) — 뒤에서 본 근접(`wake-back.png`)에 링과 골이 뚜렷. 블록 전단(`?shear=0.25,0`): 물 위 비행기 render (0.62,−0.23,1.92) vs raw (0.5,0,1.85) 로 수면과 같이 움직이고 공중은 render == raw. **메모**: three `makeShear(xy,…)` 는 구현상 y' += xy·x (x 를 y 로 미는 게 아니라 y 를 x 로) — 기존 블록 흔들기 코드는 그대로 두고(사용자가 확인한 결과물) 비행기는 행렬을 그대로 따라가므로 무관.
