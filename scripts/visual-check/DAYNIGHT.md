# 낮밤 주기 10단계 — 결과 정의 (2026-10-11)

기준선(before): `/sea` 라군은 항상 한낮 — 조명 고정(반구광 1 + 방향광 2), 물·모래·지층·생물 셰이더는 빛을 상수로 굽고, 배경은 종이색 CSS. 해·달·별·밤 조명 없음. 계측(`stepn0`, M4 Pro · 1440×900 · DPR 2, 개발 서버): 60.2fps · worst 17ms · draws 87 · tris 390.2k · GPU 중앙값 2.56ms(p95 3.99).
요청: 실제 1시간 = 라군의 하루 24시간. 시간대별로 밝기·해·달·별·섬/방갈로 조명을 알아서 세팅해 섬을 더 사실적이고 예쁘게.
품질 기준 캡처: `.visual-check/stepn0/sea.png`(한낮 기준선 — 낮 장면은 이 밝기·색감을 지킨다), `stepn0/sea-mobile.png`.

**사용자 방향 수정 (루프 중 세 번 — 목표표는 최종 방향 기준)**
1. (1단계 뒤) "사실적일 필요 없이 별·달이 하늘에 크게 떠다녀도 된다, 재밌게, 젤리·인형에 맞춰" → 인형 해(구슬 눈·볼터치)·초승달 인형·쿠션 별·솜 구름 + 화면 전체 하늘 그라데이션 (`stepn2`~`stepn9`).
2. (9단계 중) "배경이 다 바뀌면 너무 장난 같다, 젤리 위쪽만" → 배경은 종이색 그대로, 장난감을 블록 위 월드 공간으로 (`stepn10`).
3. (9단계 중) "밤하늘 별·달이 너무 장난 같다, 멋있게 + 빛나게, 젤리 모양 환경 안에 담긴 것처럼" → 블록 위에 **투명한 젤리 돔(하늘 캡슐)** 을 씌우고 그 안에 빛 구슬 달(위상 음영·크레이터·달무리)·해(금빛 원반 + 코로나)·십자 광채 별빛을 담음. 얼굴 있는 인형 해·달·쿠션 별은 삭제 (`stepn11`~`stepn12`).

## 설계 결정 (기본값)
- 시각 = 벽시계: `hour = (지금 초 mod 3600) / 3600 × 24` — 매시 정각이 자정, 30분이 정오. 새로고침·여러 탭에서도 같은 시각. `?hour=H` 고정, `?daylen=초` 하루 길이 덮어쓰기, `?sky=0` 하늘 돔 끄기(성능 A/B) — 모두 점검용.
- 조명 상태는 `sea/dayCycle.ts` 의 키프레임 표(13개) 하나가 단일 진실(하늘 위/아래 색, 주광 색·세기, 보조광, 반구광, 자체 조명 셰이더용 환경광 배율, 별 양, 조명 켜짐). 키 사이는 smoothstep 보간.
- 자체 조명 셰이더(수면·옆면·모래·지층·빛줄기·생물·열대어)는 공용 유니폼 `ENV`(`components/three/sceneEnv.ts`)를 같은 객체로 참조 — 한 번 갱신으로 전부 바뀐다. 수조를 떠나면 `resetEnv()`.
- 라이트 개수는 고정(반구광 + 주광 + 보조광), 색·세기·방향만 바꾼다(개수가 바뀌면 모든 재질 재컴파일). 주광은 해가 지면 달 방향으로 넘어간다.
- 화면 배경은 바꾸지 않는다. 하루의 색은 젤리(물·섬)와 젤리 돔 안에서만.
- 젤리 돔·해·달·별·구름은 레이어 1 — 굴절 패스(수면 아래 장면)에선 빠진다.
- 밤 조명은 PointLight 없이: 창·문·전구는 발광 재질(glass·bulb 버킷), 후광은 가산 점 스프라이트 1 드로우, 빛 웅덩이는 수면(방갈로 수중등 8)·모래(섬 횃불 4) 셰이더의 가산 항.
- 패널엔 라군 시각 읽기 전용 한 줄(`HH:MM · 밤/새벽/아침/낮/노을`)만 — 조작 없음.

## 단계별 기록
1. 뼈대(`stepn1`): **함정** `dayCycle.ts` 와 `DayCycle.tsx` 는 macOS(대소문자 무시)에서 `./DayCycle` import 가 .ts 로 풀려 TS1149 → 컴포넌트 파일을 `LagoonDay.tsx` 로. 라이트만 바꾸면 표준 재질(야자수·방갈로)만 어두워지고 물·모래는 그대로(자정 94%).

## 후속 1 — 뚜껑을 큐브에 맞춤 (2026-10-11)
